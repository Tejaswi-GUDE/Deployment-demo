From Code to Live Website

This website demonstrates the journey of writing code locally on your computer, tracking it with Git, sharing it on GitHub, and deploying it live for the world with Vercel.

How It Works

Step 1

1. Git

Git is a tool on your computer that saves snapshots of your work. Think of it like saving checkpoints in a video game so you never lose your progress.

Step 2

2. GitHub

GitHub is an online website where you store and backup your Git code in the cloud. It allows you to share your project and collaborate with other developers.

Step 3

3. Vercel

Vercel takes the code stored on GitHub and automatically turns it into a live, public website with its own URL that anyone on the internet can visit.
