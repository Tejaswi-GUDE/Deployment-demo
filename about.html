About This Project

Learn what Git, GitHub, and Vercel do, and how they connect to take your website live.

The Three Pillars

What Git Does

Git is a version control system that runs on your local machine. It tracks every change you make to your files. If you make a mistake, you can always rewind back to an earlier working version.

What GitHub Does

GitHub is a cloud hosting platform for Git repositories. It keeps a safe copy of your project online so you can share your work with others, collaborate with teammates, and connect to deployment services.

What Vercel Does

Vercel is a cloud deployment platform. It connects directly to your GitHub repository. Whenever you push new code to GitHub, Vercel automatically updates your live website in seconds.

5 Steps to Deploy a Website

  1. Write Code Locally: Create or edit your HTML, CSS, and JavaScript files on your computer.
  2. Save Changes with Git: Use git add and git commit to record a snapshot of your updates.
  3. Push to GitHub: Use git push to upload your committed code to your repository on GitHub.
  4. Connect to Vercel: Import your GitHub repository into Vercel with just a few clicks.
  5. Share Your Live Link: Vercel gives you a public link (URL) that you can share with friends and recruiters!
