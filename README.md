# Git & Deploy Playground 🚀

A simple starter website to learn **Git**, **GitHub**, and **Vercel** deployment in minutes.

---

## 📂 Project Files

- **`index.html`** – Home page with a "Try It" button.
- **`about.html`** – About page explaining the workflow.
- **`style.css`** – Clean styling (colors, layout, mobile responsive).
- **`script.js`** – Interactive button message.

---

## ⚡ Quick Start: 5 Steps to Live

### 1. Download the Code (Fork & Clone)
1. Click **Fork** at the top right of this GitHub page to make a copy in your account.
2. Click the green **Code** button and copy the URL.
3. Open your terminal and run:
   ```bash
   git clone https://github.com/YOUR-USERNAME/git-deploy-playground.git
   cd git-deploy-playground
   ```

### 2. View It Locally
- Simply double-click **`index.html`** to open it in your browser. No setup or installation needed!

### 3. Make a Change
1. Open **`index.html`** in any text editor (like VS Code or Notepad).
2. Change the main heading:
   ```html
   <h1>From Code to Live Website</h1>
   ```
   to:
   ```html
   <h1>Welcome to [Your Name]'s Website!</h1>
   ```
3. Save the file and refresh your browser to see your change.

### 4. Save & Push to GitHub
In your terminal, run these 4 simple Git commands:

```bash
git status               # See modified files
git add .                # Stage your changes
git commit -m "My update" # Save checkpoint
git push origin main     # Upload to GitHub
```

### 5. Deploy on Vercel
1. Go to [vercel.com](https://vercel.com) and log in with **GitHub**.
2. Click **Add New...** → **Project**.
3. Find **`git-deploy-playground`** and click **Import**.
4. Leave all default settings and click **Deploy**.
5. 🎉 Your website is live with its own public link!

